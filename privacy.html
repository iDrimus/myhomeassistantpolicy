Privacy Policy

Application: Personal Home Assistant Google Drive Integration

Last updated: October 13, 2026

1. Application Operator and Purpose

This application is used with a personal Home Assistant installation operated by an individual. It connects Home Assistant to the operator's Google Drive account to provide cloud storage for Home Assistant backups.

Application homepage: https://ha.drimus.mom/

This is an independent personal installation. It is not an official website or service operated by Google or the Home Assistant project.

2. Google User Data Accessed

When the user authorizes Google Drive access, the integration accesses the Google Drive resources permitted by the granted OAuth permissions. Depending on the integration version and configuration, this may include backup files, file names, file identifiers, file sizes, and other metadata required to manage backups.

The integration is configured to store Home Assistant backups in a dedicated folder in Google Drive. The precise scope of access is determined by the OAuth permissions granted to the integration.

3. How Google User Data Is Used

Google user data is used to provide the Google Drive functionality requested by the Home Assistant operator. This may include uploading backups, listing existing backups, checking backup metadata, and managing or deleting backups according to the configured functionality.

Google user data is not sold and is not used for advertising, personalized advertising, or creating advertising profiles.

4. Data Storage

Backup files are stored in the user's Google Drive account. Home Assistant may store OAuth credentials or access and refresh tokens locally to maintain the authorized connection to Google.

The Home Assistant operator is responsible for securing the Home Assistant installation, its configuration, stored credentials, and any locally retained backup data.

5. Data Sharing and Disclosure

Google user data is not sold or shared with third parties for their independent purposes. Data is transmitted to Google as necessary to authenticate the user and provide Google Drive functionality.

Google processes information under its own applicable privacy policy and service terms. The operator does not use Google user data for purposes unrelated to the configured Home Assistant integration.

6. Data Retention and Deletion

Backup files remain in Google Drive until they are deleted by the user or through the configured backup-management functionality. Removing the integration does not necessarily delete files already stored in Google Drive.

The user can delete backup files directly in Google Drive. Locally stored integration credentials can be removed through the applicable Home Assistant integration and credential settings.

7. Revoking Google Drive Access

The user can revoke the application's access at any time through their Google Account security settings by reviewing and removing the application's access to their Google Account.

Revoking access prevents the integration from continuing to access Google Drive using that authorization. It does not automatically delete backup files already stored in Google Drive.

8. Security

Access to Google Drive is based on the permissions granted by the user. The operator takes responsibility for protecting the Home Assistant installation and its stored credentials. No method of electronic storage or transmission can be guaranteed to be completely secure.

9. Children's Privacy

This personal integration is not specifically directed at children and is not designed to collect personal information from children.

10. Changes to This Policy

This policy may be updated when the integration's functionality or data-handling practices change. The latest version will be published on this page with its updated date.
