Home Assistant Google Drive Backup

This website provides information about a personal Home Assistant installation that uses Google Drive to store and manage backups.

About the application

Home Assistant is a home automation platform. This personal installation uses Google Drive integration functionality to upload and manage backup files in the operator's Google Drive account.

Data and privacy

Google Drive access is used only for the backup functionality configured by the operator. Information about data access, use, storage, retention, and access revocation is available in the privacy policy.
